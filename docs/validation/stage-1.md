통합 테스트에서는 실제 `MainScene`을 플레이 모드로 실행해 다음을 확인했습니다.

- AI 대기 중 재시작하면 이전 AI 작업이 취소된다.
- AI 요청을 여러 번 보내도 응답은 한 번만 적용된다.
- 일시정지 중 AI 작업이 취소되고, 재개 후에만 새 요청이 진행된다.
- 승급 선택 전에는 AI가 시작되지 않는다.
- 승급으로 체크메이트가 되면 결과창이 유지되고 AI가 시작되지 않는다.

엔진 평가지표와 Quiescence의 정확성은 3단계 범위이며, 탐색 도중 UI가 멈추지 않도록 만드는 시간 제한·비동기 처리는 5단계 과제입니다.

원본 `MainScene`, `TrainingScene`, `StateString`, 빌드 설정의 기존 변경은 해시 비교로 보존을 확인했습니다. 로컬 상세 로그, XML 결과, 실행 파일, 검증 checkout은 저장소에 포함하지 않습니다.
